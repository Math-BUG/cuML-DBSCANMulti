# Baseline de comparação (RAPIDS) e cabeçalhos C++ do build.
#
# Instalado no MESMO venv de requirements.txt, em etapa separada, porque é um download
# grande e é a parte que mais falha em cluster:
#
#   INSTALL_CUML=1 bash scripts/setup_env.sh
#
# Todos os componentes RAPIDS diretos ficam na MESMA série 26.02 da tag vendorizada.
# O curinga fixa a série e admite apenas correções 26.2.x; dependências transitivas não são
# inventadas aqui. A execução citável deve versionar o requirements.lock.txt produzido
# pelo pip no próprio cluster. RAPIDS 26.02 suporta Python 3.10 e CUDA 12.2--12.9:
# https://docs.rapids.ai/platform-support/#rapids-26-02
--extra-index-url https://pypi.nvidia.com

# Versão observada nos logs A100 que originaram os números preliminares do README.
cupy-cuda12x==14.1.1
cuml-cu12==26.2.*

# Trazem os cabeçalhos C++ em site-packages/{libraft,librmm}/include, usados para
# compilar o binário CUDA. Vêm como dependência do cuml-cu12, listados aqui só para
# deixar explícito de onde saem.
libraft-cu12==26.2.*
librmm-cu12==26.2.*

# cuVS: é ele que faz a busca de vizinhança do DBSCAN do cuML, e o backend padrão do nosso
# binário usa a mesma chamada. Ao contrário de libraft/librmm, NÃO veio junto do cuml-cu12
# na instalação do ClusterGPU/UFV — por isso está listado explicitamente.
libcuvs-cu12==26.2.*

# Dependência transitiva dos headers do RAFT: raft/core/logger.hpp inclui
# rapids_logger/log_levels.h. A versão independente é congelada no requirements.lock.txt
# gerado no próprio cluster.
rapids-logger
